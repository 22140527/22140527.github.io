Computer Systems

Design and Build

The components and software are absolutely essential in the computer building stage becuase they make up the computer itself and what it can handle and cant handle

Compatability

All components must work together for example the motherboard must support the CPU and RAM type and the power supply must be powerful enough for all hardware

Operating Systems

Operating system is needed for the computer to run at all ( windows, linux, macOS ) It controls what program types it can run, user interface and how it generally runs different operating systems run in different ways for example apps and files on windows may not be compatabile on linux or may need different file type

Drivers

Special types of software that listens to hardware ( Printer driver, GPU drivers, Bluetooth drivers ) without drivers components may not work correctly.Sometimes you may need to update the drivers for the components to work correctly or fix minor bugs and problems ( GPU drivers )

What is the main use of the computer?

The use of the computer will significantly change the way its built and the price range needed for example a gaming computer will be far way more expensive than a normal computer for work or office. If you use it oftenly you may think about getting better parts for the long run to save money in the future especially if you are a gamer. If you use it as a work station and for work you may think about getting a laptop instead of a computer for the ease of taking it to different places ( meetings, public places, work on the go)
