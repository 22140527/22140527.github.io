End of Life

Wiping the computer

If you are planning to sell the computer it is CRUCIAL to delete ALL files from personal information to game files EVERYTHING needs to be wiped so that it cannot be accessed by anybody else by mistake or for malicious purposes.

Disassemble the Computer

Taking apart a computer is really important for protecting personal data and ensuring a proper environmental disposing. It allows secure remoal and prevent data theft and the seperation between valuable and hazardous materials for safe and responsible recycling that is good for the environment.

Recycling

Prevents not needed waste in the environment. Computers contain very hazardous materails that can affect the environment in a very wrong way if disposed in the wrong way.
